# Loan Interest Rate Prediction

> **Archived learning project (2023).** This repository remains public as part of my applied machine-learning foundations. For current AI product and research work, see the selected projects at the bottom of this page.

`Python` · `Machine Learning` · `Regression` · `Feature Engineering` · `Model Comparison`

This project builds and compares statistical and machine-learning models for predicting the interest rate assigned to a loan. It covers the complete tabular modeling workflow, from data cleaning and exploratory analysis through feature engineering, model selection, tuning, and final test-set prediction.

## Project workflow

```text
Understand the schema and target
              ↓
Clean and prepare the data
              ↓
Exploratory data analysis
              ↓
Feature engineering
              ↓
Train seven candidate models
              ↓
Compare validation performance
              ↓
Tune the selected approach
              ↓
Generate predictions for the held-out test data
```

## Data

The project includes:

- A training dataset with known interest rates.
- A test dataset with unknown interest rates.
- A text file describing the available columns.

The repository should be treated as an educational modeling exercise rather than a production lending system.

## Responsible-use limitations

- A predictive interest-rate model can reproduce historical bias present in the training data.
- Model performance alone is not sufficient for lending decisions; fairness, explainability, calibration, regulatory review, and human oversight are essential.
- Sensitive and proxy variables require careful analysis before any real-world use.
- This project does not provide financial advice and is not designed for automated credit or underwriting decisions.
